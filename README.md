## Projects

### Avionics Intrusion Detection System
A security system focused on detecting anomalous activity in ARINC 429 avionics communication data. I have worked on protocol-aware analysis, anomaly detection, visualization, and interpreting telemetry from a security perspective.

### CelestiNav
An offline celestial navigation system designed to work without GPS or an internet connection. The idea is to use a phone camera and celestial observations to estimate navigation information, providing an alternative when conventional positioning systems are not available.

### LunaX
A computer-vision pipeline for extracting useful structures from lunar imagery. The system looks at things such as:
- Craters
- Ridges
- Texture changes
- Local features
- Feature descriptors
- Geometric relationships between terrain features


The larger idea is to turn raw lunar imagery into a structured representation that can be used for image correspondence and navigation. It also performs hazard mapping using morphology and ML models trained on crater data

### OrbitalTrust
A satellite-image authenticity and forensic analysis concept. The project explores combining several forms of evidence instead of relying on a single classifier, including image manipulation analysis, synthetic-image detection, sensor noise, metadata integrity, cryptographic hashing, geospatial consistency, and explainable evidence localization. 

### VERITAS
A geometric verification system for geospatial AI. The idea came from a fairly simple problem: satellite images can be misaligned, and downstream AI systems can interpret that misalignment as real-world change. VERITAS focuses on establishing whether two images are actually geometrically comparable before allowing a change-detection system to draw conclusions.

### From-Scratch Systems
I have also spent time building systems without relying entirely on high-level abstractions. Some of the things I have experimented with include a custom CPU emulator and mathematical/ML-oriented engines. Those projects shaped how I approach engineering: understand the abstraction, break it down, implement it, test it, and then improve it.
